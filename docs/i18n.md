# Internationalization

Last updated: 2026-06-09

Antdpro6 officially supports two frontend locales:

- `zh-CN`
- `en-US`

Template-only locale packs such as `fr-FR`, `ja-JP`, `pt-BR`, `bn-BD`, and `zh-TW` have been removed to avoid stale or partially translated UI.

## Rules

- Add or update text in both `src/locales/zh-CN` and `src/locales/en-US`.
- Keep root locale files and namespace files aligned: `component`, `form`, `globalHeader`, `menu`, `pages`, `pwa`, `settingDrawer`, and `settings`.
- Do not hard-code new UI labels in page components when the text is shared, navigational, or user-facing.
- Keep the default locale as `zh-CN`; browser language must not override it.

## Checks

Run:

```bash
pnpm run i18n:check
```

The check enforces:

- only `zh-CN` and `en-US` exist under `src/locales`
- both root locale files and namespace files contain the same keys

## Adding A New Locale Later

1. Copy `src/locales/en-US.ts` to `src/locales/<locale>.ts`.
2. Copy `src/locales/en-US/` to `src/locales/<locale>/`.
3. Translate every value.
4. Update `scripts/check-i18n.cjs` `allowedLocales`.
5. Run `pnpm run i18n:check`, `pnpm run tsc`, and `pnpm run build`.
